# shrekNX

Экспериментальный homebrew-порт **Shrek 2 для PC (KnowWonder, 2004)** на Nintendo Switch и Android. Нативные x86-модули игры статически переводятся в C и собираются для ARM64; Win32, Direct3D 8, ввод и звук обслуживает слой совместимости. macOS на Apple Silicon используется для разработки и проверки.

В репозитории — код порта, рекомпилятор и инструменты. **Для сборки и запуска нужна собственная совместимая копия PC-игры.** Файлы игры, сгенерированный из них C-код, обложки и готовые игровые NRO здесь не распространяются.

## Состояние

**Версия 0.3.0** ([изменения](CHANGELOG.md)). Игра запускается на настоящей Switch: работают меню, уровни (болото, `3_The_Hunt_Part4`), звук, ролики, управление геймпадом с легендой кнопок и Quick Menu, вибрация и сохранения. Полное прохождение и визуальная сверка с оригиналом ещё не подтверждены; Linux — `[проверить]`.

| Возможность | Что проверено |
|---|---|
| Switch | 0.3.0: проверено в портативе (1280×720, CPU 1020 МГц, полный режим памяти): меню 60 FPS, ролики 50–60 FPS, `1_Shreks_Swamp` **95,5% кадров в 60 FPS** (с PGO, 0 хичей, 0 диалоговых фризов), `3_The_Hunt_Part4` **49–53 FPS** на 7 300+ кадрах без краша автосейва, сохранение **347–364 мс** (`FastLoad`); легенда, Quick Menu, вибрация, подсказка в applet-режиме; хуки HOME/сон/док, гамма и повторный запуск с кешем бинарников GL — `[проверить]` |
| Производительность | 0.3.0 на Switch (болото, 1280×720, CPU 1020 МГц, локальный PGO + `hot_order.ld`, 3 582 кадра): среднее **16,42 мс**, медиана **16 мс**, p95 **17 мс**, max **34 мс**, 0 хичей, активный Core 1 **14,34 мс/кадр (~69,7 uncapped FPS)**; без PGO на той же сборке — медиана 17 мс, p95 21 мс, 55,2% кадров ≤17 мс (для сравнения: на 0.1.0 с PGO было 38,0–38,8 FPS) |
| macOS arm64 | Меню (опциональный 4:3 pillarbox, легенда кнопок, Quick Menu), болото (5/5 сверок `SNX_*_CHECK=1`, A/B GPU shadow blur, `SNX_RENDER_THREAD=0`), `3_The_Hunt_Part4`, звук и ролики; **14 CTest** (включая ASan+UBSan), **24 теста рекомпилятора** и полный `difftest` 12/12 модулей (11 265 pass, 0 регрессий) |
| Android | APK собирается в CI и запускается на телефонах (Adreno, Mali): лаунчер, редактируемое экранное управление, прослойка OpenGL ES 3.0, обновления из GitHub Releases — [docs/ANDROID.md](docs/ANDROID.md) |

Остаются фризы при первом появлении материалов (до заполнения кеша программ) и сохранении, растянутый по ширине 2D HUD во время игры (для страниц меню доступен опциональный режим 4:3 в Quick Menu) и проверка полного прохождения на Switch. Профиль PGO не входит в репозиторий: обычная сборка может работать медленнее указанного замера.

## Сборка

Пошаговая инструкция: **[docs/BUILDING.md](docs/BUILDING.md)**. Основная среда разработки — macOS arm64 (также добавлена конфигурация для Linux, `[проверить]`); для Switch дополнительно нужен devkitPro.

После установки зависимостей, из корня репозитория:

```sh
python3 -m venv tools/.venv
tools/.venv/bin/python -m pip install -r tools/requirements.txt
tools/build.sh mac
ctest --test-dir build/mac --output-on-failure
```

Без игры собираются GL-пример, рантайм и самостоятельные тесты. Для игрового хоста сначала нужен перевод модулей:

```sh
tools/.venv/bin/python -I recomp/main.py gen --game game/System --out build/gen
tools/build.sh mac snx_boot
build/mac/host/boot/snx_boot --game game --user build/userdata
```

Для Switch после настройки devkitPro:

```sh
tools/build.sh switch snx_boot_nro
```

Для Android (JDK 17, Android SDK с NDK 27) — [docs/ANDROID.md](docs/ANDROID.md):

```sh
tools/android_deps.sh --ffmpeg
tools/build.sh android
```

Результат для Switch — `build/switch/host/boot/snx_boot.nro`. Файлы той же игры должны находиться в `sdmc:/switch/shrek2/game/`. Подробности первого запуска, русской версии и ошибок CRC — в инструкции сборки.

|---|---|
| `recomp/` | Поиск функций, анализ x86 и генерация C |
