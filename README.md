# shrekNX

Экспериментальный homebrew-порт **Shrek 2 для PC (KnowWonder, 2004)** на Nintendo Switch и Android. Нативные x86-модули игры статически переводятся в C и собираются для ARM64; Win32, Direct3D 8, ввод и звук обслуживает слой совместимости. macOS на Apple Silicon используется для разработки и проверки.

В репозитории — код порта, рекомпилятор и инструменты. **Для сборки и запуска нужна собственная совместимая копия PC-игры.** Файлы игры, сгенерированный из них C-код, обложки и готовые игровые NRO здесь не распространяются.

## Состояние

**Версия 0.1.0** ([изменения](CHANGELOG.md)). Игра запускается на настоящей Switch: работают меню, первый уровень, звук, ролики, управление геймпадом и сохранения. Полное прохождение и визуальная сверка с оригиналом ещё не подтверждены.

| Возможность | Что проверено |
|---|---|
| Switch | Запуск в полном режиме памяти через hbmenu, 1280×720 в портативном режиме |
| Производительность | 38,0–38,8 FPS у точки сохранения в болоте при CPU 1020 МГц, с локальным профилем PGO; это замер одной сцены |
| macOS arm64 | Меню, болото, звук и ролики; автоматические проверки рантайма |
| Android | Лаунчер, редактируемое экранное управление, прослойка OpenGL ES 3.0 — **ещё не собиралось и не запускалось**, [docs/ANDROID.md](docs/ANDROID.md) |
| Русская версия | Отдельная сборка из DLL локализации «Новый Диск»; запускается на macOS и Switch, управление на Switch после последних исправлений не перепроверено |

Остаются фризы при первом появлении материалов и сохранении, неполная реализация D3D8, растянутый по ширине 2D-интерфейс и проверки переходов между уровнями. Профиль PGO не входит в репозиторий: обычная сборка может работать медленнее указанного замера.

## Сборка

Пошаговая инструкция: **[docs/BUILDING.md](docs/BUILDING.md)**. Поддерживаемая среда сборки — macOS arm64; для Switch дополнительно нужен devkitPro.

После установки зависимостей, из корня репозитория:

```sh
python3 -m venv tools/.venv
tools/.venv/bin/python -m pip install -r tools/requirements.txt
tools/build.sh mac
ctest --test-dir build/mac --output-on-failure
```

Без игры собираются GL-пример, рантайм и самостоятельные тесты. Для игрового хоста сначала нужен перевод модулей:

```sh
tools/.venv/bin/python -I recomp/main.py gen --game game/System --out build/gen
tools/build.sh mac snx_boot
build/mac/host/boot/snx_boot --game game --user build/userdata
```

Для Switch после настройки devkitPro:

```sh
tools/build.sh switch snx_boot_nro
```

Для Android (JDK 17, Android SDK с NDK 27) — [docs/ANDROID.md](docs/ANDROID.md):

```sh
tools/android_deps.sh --ffmpeg
tools/build.sh android
```

Результат для Switch — `build/switch/host/boot/snx_boot.nro`. Файлы той же игры должны находиться в `sdmc:/switch/shrek2/game/`. Подробности первого запуска, русской версии и ошибок CRC — в инструкции сборки.

| Каталог | Назначение |
|---|---|
| `recomp/` | Поиск функций, анализ x86 и генерация C |
| `runtime/` | Гостевая память, загрузчик, нативные замены, HLE Win32/D3D8 |
| `platform/`, `host/` | SDL/OpenGL (ES), запуск на macOS, Switch и Android |
| `android/` | Лаунчер и экранное управление Android (Gradle, Kotlin) |
| `tests/` | Самостоятельные тесты и сравнение с Unicorn на локальных файлах игры |
| `tools/` | Сборка, анализ файлов, профилирование и перенос на Switch |
