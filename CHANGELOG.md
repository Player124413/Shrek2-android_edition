# Изменения

Формат — по версиям, новые сверху. Замеры производительности относятся к указанной сборке и сцене.

## Не выпущено

### Android (не проверено на устройстве)

- **Порт:** APK для arm64-v8a, Android 7.0+, OpenGL ES 3.0; игра — тот же сгенерированный код поверх SDL2.
  Прослойка GL 4.1 → ES 3.0 (`platform/gles_shim.c`): форматы D3D8, DXT на ЦП без S3TC, чтение через FBO,
  базовая вершина, D3DCOLOR и плоскости отсечения в шейдерах.
- **Лаунчер:** импорт игры из любой папки или чтение по пути, проверка файлов, пресеты под слабые/средние/мощные
  телефоны, журнал, переменные `SNX_*`, отдельные пакеты для английской и русской версий.
- **Экранное управление:** мультитач, статичный стик (плавающий — по желанию), камера пальцем, скольжение по
  кнопкам, вибрация; прячется в меню и при подключённом геймпаде. Редактор раскладки в лаунчере и прямо в игре: перемещение, размер щипком,
  прозрачность, скрытые элементы (крестовина, правый стик, зелья 1–9).
- **Скорость:** потоки на больших ядрах и ADPF, кэш программ GL на диске, доля разрешения, ограничение FPS,
  16-битные текстуры, режим стабильной производительности, корректная пауза при сворачивании.
- **Исправлено:** повторный запуск игры не отвечал на касания — процесс прошлой игры зависал на выходе (`exit()`
  звал деструкторы библиотек при живых потоках рендера и звука), и новый запуск попадал в него. Теперь выход, как
  на Switch, завершает процесс сразу (после сброса файлов), лаунчер добивает застрявший процесс перед запуском, а
  «Назад» спрашивает подтверждение и выходит без ожидания потока SDL. [проверить на устройстве]
- **Стик:** прилипание к осям (25°) — влево/вправо без примеси «вперёд/назад» (карнизы); кнопки L/R и «Камера»
  убраны.
- **Диагностика ввода:** строки `[touch]` в `snx.log` (раз в 10 с: цикл ввода, окно с фокусом, меню, опросы
  DirectInput; первые нажатия и касания), размеры `User.ini`/`game.ini` при старте; в лаунчере «Журнал» →
  «Поделиться» — журналы двух последних запусков текстом и файлом в «Загрузки».
- **Язык:** лаунчер, редактор и подписи кнопок — на русском или английском по языку телефона.
- **Обновления:** постоянный ключ подписи и растущий `versionCode` — новая версия ставится поверх старой.
- **Авторы:** окно «О порте» (Player1444, t.me/player1444ports, спасибо Ananasiy/shrekNX) при первом запуске.
- **CI:** сборка с игрой по ссылке из «Run workflow»; артефакт — сам APK, без zip.

### Исправлено

- **Подбор монет на бонусных уровнях** (`Beanstalk_bonus*`): скрипт игры при каждом подборе монет и предметов
  здоровья сохраняет конфиг контроллера героя (`SaveConfig`). Движок после этого перечитывает конфиг в умолчания
  всех 51 класса контроллеров, ищет их обходом всех объектов и переписывает `User.ini`, перед записью открывая его
  ради размера. Теперь перечитываются только классы, чьи секции ini изменились (3 из 51), подклассы берутся из
  списка, кеш ini читается без вызовов кода игры, размер только что записанного файла известен без открытия, а
  запись `User.ini` идёт в фоновом потоке. Switch, подборы с паузой 150 мс: 3,7–4,4 мс на монету (с одним пропуском
  перечитывания было 10–17 мс, кадр пропускался на каждой монете). macOS: 2,0 → 0,5 мс.

### Ускорено

- **Открытие файлов на Switch:** существование и тип файла берутся из кеша листингов каталогов, размер — одним
  запросом `GetSize`. Раньше каждое открытие существующего файла делало `stat` (пять-шесть запросов к сервисам,
  включая перевод метки времени), а `GetFileSize` — `fstat`.

## 0.1.0 — 2026-11-18

Первая публичная версия исходников. **Shrek 2 для PC запускается и играется на настоящей Nintendo Switch.**
Выпуск содержит только код порта и инструменты; для сборки нужна собственная совместимая копия игры.
Готовые игровые NRO не распространяются.

### Что работает

- **Switch:** NRO через hbmenu в полном режиме памяти, 1280×720 в портативном режиме. Меню, первый уровень,
  катсцены, магазин, зелья, сохранения.
- **Производительность:** 38,0–38,8 кадр/с у точки сохранения в болоте при CPU 1020 МГц с локальным профилем PGO;
  34,2–35,3 кадр/с без PGO. Это замер одной сцены.
- **Звук и видео:** музыка Ogg Vorbis, звуки и диалоги Bink (собственный декодер Bink audio), ролики Bink
  через libavcodec, OpenAL.
- **Управление:** геймпад как джойстик DirectInput (стики, привязки `Joy*` в `User.ini`), крестовина по
  элементам меню, L/R по вкладкам, касания, значки кнопок Switch. Испорченные привязки в `User.ini`
  восстанавливаются при запуске.
- **Локализации:** английская версия и отдельная сборка «Шрек 2» из DLL локализации «Новый Диск».
- **macOS arm64:** меню, болото, звук и ролики; основная среда разработки и проверки.

### Из чего состоит порт

- **Рекомпилятор** (`recomp/`): поиск функций, анализ x86 и x87, генерация C для всех 12 нативных модулей
  игры. Дифф-тесты против Unicorn: в игровых модулях нет необъяснённых расхождений.
- **Рантайм** (`runtime/`): гостевая память (окно 1 ГБ на Switch), кучи, TEB/PEB, потоки, загрузчик и
  DllMain, `setjmp/longjmp`, исключения C++ и SEH гостя, нативные замены горячих функций.
- **HLE Win32 / DirectX:** реализованы все импорты игры — kernel32 с VFS и оверлеем, user32/gdi32, winmm,
  COM (ddraw, dinput8), `IDirect3DDevice8` поверх OpenGL в отдельном потоке рендера, binkw32, vorbisfile, OpenAL.
- **Платформа** (`platform/`, `host/`): SDL2/OpenGL, запуск на macOS и Switch, обработчик падений с
  адресом гостя и трассировкой стека.
- **Инструменты** (`tools/`): сборка, PGO, профилирование, разбор пакетов Unreal, заливка на Switch по FTP,
  проверка состава публикации.

### Известные ограничения

- Полное прохождение, загрузка сохранений и переходы между уровнями ещё не проверены.
- Фризы при первом появлении материалов и при сохранении (кадр сохранения — 0,77–0,79 с на Switch).
- D3D8 реализован не полностью; 2D-интерфейс растянут по ширине в 16:9; визуальной сверки с ПК не было.
- Управление после последних исправлений проверено на macOS, повторная ручная проверка на Switch нужна.
- Профиль PGO не входит в репозиторий: обычная сборка медленнее указанного замера.

Устройство порта, замеры и приоритеты — `AGENTS.md`.
